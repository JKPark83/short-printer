# shorts-printer 화면 와이어프레임

디자인 근거는 ui-ux-pro-max 스킬이 만든 파일이다.

- `design-system/shorts-printer/MASTER.md`: 색·글꼴·간격·체크리스트
- `design-system/shorts-printer/pages/dashboard.md`, `pages/job-detail.md`, `pages/trends.md`: 화면별 덮어쓰기

스타일은 Minimalism & Swiss, 다크 터미널 톤이다. 밀도 8, 움직임 3, 변주 3으로 정보가 촘촘하고 움직임이 적다.

- **아직 없는 결과:** 단계 카드에 "이 단계가 끝나면 여기에 나와요"를 흐리게 보여 준다.

**상태별 화면**

- **빈 목록:** "아직 분석이 없어요. 왼쪽에서 [분석 시작]을 누르면 지금 뜨는 쇼츠를 모아 와요."
- **키 없음:** [분석 시작]을 끄고 노란 배너에 YouTube Data API 키 만드는 4단계를 보여 준다. Claude 키가 없으면 "분석 단계에서 멈춰요"라고 미리 알린다.
- **대기:** "대기열에서 차례를 기다려요. 앞 작업이 끝나면 시작해요."
- **진행 중:** 단계 노드와 진행 막대에 "3/8"을 띄우고, 아직 안 끝난 영상은 "분석 중·대기" 배지를 단다. 1.5초마다 상태 API를 불러 바뀐 조각만 바꾸고, 재생 중인 미리보기가 있는 조각은 건드리지 않는다.
- **썸네일만(meta_only):** "영상을 받지 못해(봇 확인 등) 썸네일과 제목·설명·통계만으로 봤어요. 컷과 장면은 없어요." 배너에도 몇 개였는지 남긴다.
- **영상 하나 실패:** "분석하지 못했어요: 오류. 추천을 고를 때는 빼요."
- **실패:** 빨간 배너에 "실패: 단계"와 오류를 그대로 보여 주고, [다시 시도]는 끝난 단계와 끝난 영상을 건너뛴다.
- **중단:** "서버가 꺼져 멈췄어요" 배너와 [다시 시도].
- **아직 없는 결과:** 카드마다 "수집이 끝나면 영상마다 결과가 나와요"처럼 다음에 무엇이 나올지 알려 준다.

**대시보드 연결:** 대시보드에 "지금 만들 만한 주제" 카드를 두고, 최신 완료 분석의 추천 상위 3개(총점, 왜 지금, 목소리, [만들기])와 "근거 보기" 링크를 보여 준다. 추천이 없으면 "아직 추천이 없어요. 주제 찾기에서 …"를 띄운다. 추천에서 만든 작업은 상세 머리에 "추천 주제에서 만듦" 링크와 참고 방향을 보여 준다.

**반응형:** 375px에서는 영상 카드가 2열, 분석·추천은 한 줄로 쌓이고, 단계 표시기는 세로 목록이 된다. 1024px 이상에서는 오른쪽 360px에 사용량과 로그가 붙는다.

## 4. 반응형

| 폭 | 대시보드 | 작업 상세 |
|---|---|---|
| 375px | 한 줄로 쌓기. 숫자 타일은 2×2 | 단계 표시기는 세로 목록. 영상이 단계 카드 위로 올라온다 |
| 768px | 한 줄로 쌓기. 타일 4개 한 줄 | 단계 표시기 가로. 영상과 카드는 위아래 |
| 1024px 이상 | 왼쪽 360px 고정, 오른쪽 나머지 | 왼쪽 카드, 오른쪽 360px 영상·로그(스크롤 따라 붙음) |
| 1440px | 최대 폭 1400px | 최대 폭 1200px |

## 5. 스킬 규칙을 어떻게 적용했나

**적용한 규칙**

- **여러 단계 진행은 단계 표시기로 보여 준다.** 단계 표시기는 `<ol>`이고, 진행 중 노드에 `aria-current="step"`을 단다.
- **제출 버튼은 로딩, 성공, 오류로 상태를 알려 준다.** 오류는 토스트(`role="status"`)로 띄운다.
- **진행 영역에는 `aria-busy`를 단다.** 작업이 돌 때 단계 표시기에 붙인다.
- **미디어 자리는 미리 잡는다.** 영상은 `aspect-ratio: 9/16`과 포스터를 쓰고, 썸네일은 `aspect-ratio`로 자리를 잡는다.
- **영상은 눌러야 재생한다.** `<video controls preload="none" playsinline>`이고 자동 재생은 없다.
- **입력칸에는 보이는 라벨을 단다.** 글자 수 카운터를 함께 둔다.
- **누를 수 있는 것에는 `cursor: pointer`를 준다.** 포커스 링은 흰색 2px으로 잘 보이게 한다.
- **호버는 150~250ms 전환을 쓴다.** 크기를 키우는 효과는 쓰지 않는다.
- **`prefers-reduced-motion`이면 스피너 회전과 전환을 끈다.**
- **아이콘은 Lucide SVG로 통일한다.** 이모지는 쓰지 않는다.
- **실시간 표시는 실제로 갱신될 때만 "갱신 중"이라고 쓴다.** 마지막 갱신 시각과 끊김 상태를 함께 보여 준다.

**버린 추천**

- **job-detail.md의 WebGL·패럴랙스·3D 효과를 버렸다.** 움직임 3과 "느린 대시보드 금지" 규칙에 어긋난다.
- **MASTER.md의 밝은 입력칸·모달 값을 버렸다.** 테두리 #E2E8F0, 흰 배경 같은 값은 다크 토큰으로 바꿨다.
- **스크롤 등장 효과(gsap)를 버렸다.** 도구 화면이라 쓸모가 적고 라이브러리 하나가 늘어난다.
