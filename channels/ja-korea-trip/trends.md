# 추천 주제 고르기 규칙

- 방한 일본인의 동기는 음식·쇼핑이 약 70%다. 맛집·카페·시장·화장품(올리브영)·쇼핑 꿀팁을 먼저 고르고, 그다음 교통·환전·T-money 같은 실전 팁을 고른다.
- 장소는 명동 → 경복궁 → 홍대 → 성수 → 강남 순으로 다룬다. 일본인 관심이 명동에서 성수로 옮겨 가는 중이라 성수 비중을 늘린다.
- 일본 연휴 직전에 맞는 주제를 우선한다: 골든위크(4월 말~5월 초), 오봉(8월 중순), 연말연시, 3연휴. 한국 계절(벚꽃·장마·단풍·겨울 추위)도 맞춘다.
- B축 꿀팁 사이에 A축 유래·역사 편을 약 30~40% 섞고, 같은 장소를 A·B 짝 편으로 고른다(例: 景福宮の由来 + 景福宮の韓服割引).
- 한일 역사 논쟁 자체가 주제인 것은 고르지 않고 excluded에 이유를 남긴다.
